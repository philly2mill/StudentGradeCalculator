# Student Grade Calculator

## Description

This Java console application displays a student's name, major, and course. It calculates the average of three assignment grades and determines whether the student passed.

A student passes when the average is 70 or higher.

## Requirements

- Java Development Kit (JDK)
- Visual Studio Code with the Java extensions

## How to Run

Open the project folder in VS Code. Open a terminal and run:

```bash
javac Assignment1/StudentGradeCalculator.java
java -cp Assignment1 StudentGradeCalculator
```

## Example Output

```text
STUDENT INFORMATION AND GRADE REPORT
Student: Chris 
Major: Computer Science
Course: CMPS 360
Assignment 1: 90.0
Assignment 2: 84.0
Assignment 3: 96.0
Average: 90.0
Status: Passed
```
