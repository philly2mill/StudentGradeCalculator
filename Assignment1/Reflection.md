Java source code is the human-readable code a programmer writes in a file with the .java extension. In my StudentGradeCalculator application, the source code declares variables, calculates an average, and uses an if/else statement to display whether the student passed. Before the program runs, the Java compiler, javac, translates this source code into bytecode stored in a .class file. Bytecode is an intermediate representation rather than instructions written for one specific processor. The Java Virtual Machine, or JVM, loads and executes that bytecode on the computer. This separation allows the same compiled program to run on different operating systems when they have a compatible JVM. If I change a grade in the source file, I must compile it again before running the updated class.
